About CloudClear

CloudClear is the web front-end of an implementation of “Thick Cloud Removal Using Cloud Mask-Guided SAR-Optical Fusion Network” (PSF-CR), S. Meng et al., IEEE JSTARS, vol. 19, pp. 4373–4388, 2026 (DOI 10.1109/JSTARS.2026.3651496).

How it works
  1. Input: a 256×256 Sentinel-1 patch (VV, VH in dB) and the co-registered cloudy Sentinel-2 L1C patch (13 bands).
  2. Preprocessing: SAR clipped to [-25, 0] / [-32.5, 0] dB, optical clipped to [0, 10000], both scaled to [0, 1]; a rule-based detector creates the cloud mask.
  3. Model: the best model from training ({{ cfg.display_name }}): frequency- and spatial-domain SAR-optical cross-alignment, cloud-mask-guided rectification and a U-shaped reconstruction network.
  4. Output: a cloud-free 13-band GeoTIFF (georeferenced), an uncertainty map from 8-view test-time augmentation, and quality metrics when a cloud-free reference is available.
Data

Models were trained on 1,149 real SEN12MS-CR-style triplets (Sentinel-1 RTC + cloudy/cloud-free Sentinel-2 L1C) from 8 regions in Asia and Latin America, with whole regions held out for testing.
